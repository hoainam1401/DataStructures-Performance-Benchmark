Wymagania: CMake 3.16+ oraz kompilator obsługujący C++20.

Szybka kompilacja bez CMake:
clang++ -std=c++20 main.cpp -o benchmark-local
clang++ -std=c++20 mainRAM.cpp -o benchmarkRAM-local

Kompilacja i testy (Windows, Linux, macOS):
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure

Testy czasu:
build/benchmark --iterations 1000 --prefill 12

Testy zużycia pamięci RAM:
build/benchmarkRAM --prefill 100000

Visual Studio umieszcza pliki wykonywalne w katalogu build/Release/.
